# WP LinkedIn Poster

WP LinkedIn Poster is a WordPress plugin that allows you to publish your WordPress posts directly to your LinkedIn company page.

The plugin connects your WordPress site with LinkedIn using OAuth authentication and lets you select the organization where posts will be published. It also allows editors to customize the content that will be sent to LinkedIn using an ACF field directly in the post editor.

## Features

🔐 **Secure LinkedIn OAuth authentication**
Connect your WordPress site to LinkedIn using the official OAuth flow.

🏢 **Organization selection**
Choose the LinkedIn company page where your content will be published.

✏️ **Custom LinkedIn content field (ACF)**
Editors can write a specific version of the content optimized for LinkedIn.

📰 **WordPress post integration**
Works directly with WordPress posts and integrates into the post editor.

📊 **Publication status column**
Adds a column in the posts list to display whether the article has already been published to LinkedIn.

## Requirements

* WordPress 6.0+
* PHP 7.4+
* Advanced Custom Fields (ACF)

## Installation

1. Upload the plugin to the `/wp-content/plugins/` directory.
2. Activate the plugin from the WordPress admin.
3. Configure your LinkedIn credentials in the plugin settings.
4. Connect your LinkedIn account and select the organization.
5. Start publishing posts to LinkedIn.
